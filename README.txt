5조 교대근무 캘린더 (비밀번호 없는 PWA 패키지)
=============================================

포함 파일 (총 6개):
- index.html      : 메인 캘린더 앱
- manifest.json   : 모바일 앱 설치 설정
- sw.js           : 오프라인 지원 서비스 워커
- icon-192.png    : 앱 아이콘 (192x192)
- icon-512.png    : 앱 아이콘 (512x512)
- README.txt      : 안내 파일

배포 및 설치 방법:
1. 압축을 푼 뒤 폴더 안의 파일 전체를 GitHub Pages 또는 Netlify Drop 등에 업로드합니다.
2. 생성된 웹 주소로 스마트폰 브라우저(Chrome, 삼성 인터넷, Safari 등)에서 접속합니다.
3. 상단의 [앱 설치] 버튼을 누르거나 브라우저 메뉴에서 [홈 화면에 추가]를 선택해 설치합니다.
